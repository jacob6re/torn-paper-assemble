# 四块撕纸拼接

交付可编辑的 HyperFrames 工程和经验证的本地 MP4。核心是同一帧的四个互补区域，而非四张独立图片。处理照片时，拼齐后停留在完整照片。

## 输入与判断

- 接受本地视频或照片、可选定格时间、节奏或入场方向。默认视频第 0 秒、恢复播放 3 秒、保持原画幅。
- 先查看原图或抽帧，判断有无人物。**有人物：先沿真实轮廓抠出完整人物作为一片，剩下背景再分三片，总数仍为四。** 无人物：按景物轮廓分四块。换素材必须重画分区，不能套用列车坐标。
- **人物以外的三块背景默认采用不规则撕裂分区。** 除画布外边缘外，分界应有肉眼可见的高低起伏、弯折与不对称形状；避免水平、垂直或长斜线平切。不能只在一条近似直线上增加细小锯齿，也不能仅靠人物遮罩形成的孔洞让规则背景看似不规则。人物遮挡之后仍可见的背景分界也要检查，尤其是上方一片的下边缘。
- 人物不能用矩形、粗多边形或生成模型重绘代替抠像；人物像素必须来自原帧。前景默认包含所有可见人物组成一个图块；用户指定主角时，提供仅含指定主角的遮罩。人物位于背景纸片上层，保持头发、脸、手臂及身体的连续轮廓，不被背景分区线切开。
- 教程录屏只是效果参考。若只有录屏，可明确裁出预览区域做低清演示；不得把教程字幕、软件界面或水印当作干净原素材。制作正式成片需要原视频。
- 仅有参考、未提供待处理素材时，可以制作 Skill 或参考演示；说明素材限制即可，不编造原视频。

## 构建

1. 在可用时先遵循 `$hyperframes` 的视频入口，再读本文件。这里的脚本已实现专门的四片拼接，不必换成通用转场。
2. 读取 [分区契约](references/pieces.md)，根据当前帧写 `pieces.json`。人物版使用 `mode: person`，第 1 片无 polygon，由人物遮罩生成；其余 3 片的多边形先覆盖整幅画面，脚本自动扣掉人物。无人版使用 `mode: scene`（默认），4 个多边形覆盖整幅画面。共享边须完全一致。坐标相对裁切后的画面。
3. 运行脚本。需要 Python 3、Pillow、FFmpeg、FFprobe；预览与渲染需要 Node.js 22+ 和 HyperFrames。只在缺失时安装依赖，不改全局设置。

```bash
python3 scripts/build.py --input /path/to/video.mp4 --frame 0 \
  --pieces /path/to/pieces.json --output /path/to/new-project
```

脚本路径相对 Skill 目录，实际调用须解析成绝对路径。输出目录须尚不存在。照片也使用同一命令。录屏裁切可显式添加 `--crop x,y,width,height`（原视频像素）。

人物版在 macOS 14+ 可用自带 Swift/Vision 自动抠像，不上传素材。其他系统、指定主角或自动抠像失败时，传入 `--person-mask /path/to/mask.png`。遮罩必须与**裁切、方向校正并取偶数尺寸后的定格帧**等大，白色表示人物、黑色表示背景。脚本阈值化为互补区域，避免半透明边缘叠加变暗。必须查看遮罩与人物图块；没有检测到人物或遮罩错误时修正后重试，不能悄悄改用普通四块。

4. 脚本生成互补 RGBA 图块、纸边层、完整定格帧、恢复片段、单一暂停 GSAP 时间线和清单。边界使用固定种子，逐帧不抖动。默认四片错峰滑入，最终均归零到原位；白边在拼齐后淡出，原帧接回同一源时间的视频。不会重绘人物或景物。
5. 在输出目录运行 `npm run check`，查看入场中段、四块拼齐、白边消失、视频恢复四个时刻。再运行 `npm run preview -- --background` 打开时间线。按当前任务的渲染授权运行 `npm run render -- --output /path/to/result.mp4`。

## 验收与边界

- 四块确实来自同一帧、同一画幅；主体和纹理在最终位置对齐，没有黑缝、重复区域或多出来的景物。
- 人物版须额外确认：第 1 片只有真实人物；第 2～4 片不含人物像素，三片并集恰好等于人物以外区域。背景上的人物空洞是拆分产生的正常形状，不补画被人物遮挡的景物。四片最后精确复原原帧。
- 在背景入场和拼齐但白边仍可见时，确认三片背景的可见共享边具有明显的不规则轮廓；上方纸片不能呈现横向平切的带状边缘。缩小到正常播放尺寸仍像直线时，先修改多边形的大轮廓，再添加细小纸纤维锯齿。
- 入场须是可见的位移与错峰，不能用四次淡入替代。白边跟着图块移动。
- 拼齐后查看完整原帧；恢复的第一帧须与定格时间匹配，不跳回视频开头。
- 音频默认：冻结开场静音，恢复片段保留其原声。若用户要求全程音乐或冻结前原声连续，需要另外设计音轨，不能声称默认已实现。
- 脚本做定格帧人物分割和静态背景分区；Agent 看图确定是否进入人物版并规划背景轮廓。自动抠像可能漏掉头发、手指或遮挡部位，须人工检查并按需修正遮罩。暂不处理真实纸张卷曲、动态逐帧分割或节拍自动识别。
- 用 FFprobe 确认成片尺寸、帧率、时长；人工看关键帧并播放检查。只通过结构检查时，不宣称效果已复刻。
- 保留用户文件，不覆盖已有工程，不默认发布到远端。
