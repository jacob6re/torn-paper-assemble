# 分区与节奏

`pieces.json` 包含恰好四个 `pieces`，以及可选的 `border`（默认 4 像素）、`hold`（拼齐停留，默认 0.35 秒）、`seam_fade`（白边淡出，默认 0.16 秒）、`background`（默认黑色）。

`mode` 可为 `scene`（默认）或 `person`。看见人物时使用 `person`。总数始终为四片：`pieces[0]` 为人物，不填写 `polygon`，`pieces[1:4]` 为背景三个多边形。背景多边形覆盖整幅画面，脚本以人物遮罩的补集扣出真正背景，不需要人工描出带孔多边形。人物保持在三片背景前方。

人物版格式示例（背景分区仅演示数据格式，按实际构图调整）：

```json
{
  "mode": "person",
  "pieces": [
    {"from": [0,1.1], "start": 0.5, "duration": 0.65},
    {"polygon": [[0,0],[0.55,0],[0.5,0.5],[0,0.62]], "from": [-1.1,-0.2], "start": 0},
    {"polygon": [[0.55,0],[1,0],[1,0.58],[0.5,0.5]], "from": [1.1,-0.2], "start": 0.18},
    {"polygon": [[0,0.62],[0.5,0.5],[1,0.58],[1,1],[0,1]], "from": [0,1.1], "start": 0.34}
  ]
}
```

可用 `--person-mask mask.png` 提供与处理后定格帧等大的灰度遮罩；未提供时在 macOS 14+ 上运行本包的 `scripts/person_mask.swift`。白色人物、黑色背景；阈值 128 后保存为 `assets/person-mask.png`。彩色图、错误尺寸、空白或满幅遮罩会报错，不自动缩放或退回景物版。

每片字段：

- `polygon`：背景／景物片至少三个 `[x,y]`，人物片不填写。相对输出帧的 0～1 坐标。背景／景物多边形先完全覆盖整帧，除共享边之外不重叠。两片共享边即使方向相反，顶点也须一一对应。避免自交。
- `from`：起点偏移 `[x,y]`，单位为画面宽、高。例如 `[0,-1.1]` 从上方滑入。终点始终 `[0,0]`，不另外缩放。
- `start`：入场开始秒数，默认按序间隔 0.22 秒。
- `duration`：入场持续秒数，默认 0.65 秒。
- `rotation`：可选初始轻微旋转角度，默认 0，入场结束归零。

无人版可先沿主体上缘画一条贯穿画面的折线，再沿下缘画第二条；上方区域按构图再分成两片，即得到四片。人物版先抠人物，再按背景景物分成三个大区域。共享边的连接点必须完全相同。背景轮廓只需中等细节，脚本会生成固定的细小锯齿；人物边缘不加轮廓扰动。不要切成等大矩形。

例如通用几何试验分区（仅用于理解数据格式，实际任务按画面重新描边）：

```json
{
  "pieces": [
    {"polygon": [[0,0],[0.6,0],[0.6,0.32],[0,0.55]], "from": [-1.1,-0.3], "start": 0},
    {"polygon": [[0.6,0],[1,0],[1,0.4],[0.6,0.32]], "from": [1.1,-0.3], "start": 0.22},
    {"polygon": [[0,0.55],[0.6,0.32],[1,0.4],[1,0.7],[0.6,0.52],[0,0.8]], "from": [-1.1,0], "start": 0.44},
    {"polygon": [[0,0.8],[0.6,0.52],[1,0.7],[1,1],[0,1]], "from": [0,1.1], "start": 0.66}
  ]
}
```

独立检查输出 `assets/piece-0.png` 到 `piece-3.png` 的透明区域。四片的非透明区域并集应等于全画面、交集应为空。图块与纸边分层，使白边在拼齐时平滑退出。配置保存在工程中，可调整后输出到新目录重新构建。
